# Contributing to Holark

Thank you for taking the time to help improve Holark.

## Issues and feedback

Bug reports, feature requests, and product feedback are welcome in
[GitHub Issues](https://github.com/holark-ai/holark/issues). Before opening a
new issue, please check whether an existing issue already covers it. Include
the behavior you expected, what happened instead, and enough environment or
repository context to reproduce the problem.

Security vulnerabilities should not be reported in a public issue. Follow the
private reporting instructions in [SECURITY.md](SECURITY.md).

## Code contributions

Holark is not currently accepting external code contributions. Please do not
open a pull request unless a maintainer has asked you to do so.

We plan to introduce a contributor agreement before opening the project to
outside code contributions. This keeps the rights to contributions clear while
Holark is developed as a Fair Source commercial product.

## Local development

Maintainers and invited contributors should follow the build and test workflow
in [docs/development.md](docs/development.md).
