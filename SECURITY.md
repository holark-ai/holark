# Security policy

## Reporting a vulnerability

Please do not report security vulnerabilities through public issues,
discussions, or pull requests.

Use GitHub's private vulnerability reporting for this repository:

https://github.com/holark-ai/holark/security/advisories/new

Include a description of the issue, its possible impact, reproduction steps,
and any suggested mitigation. Please allow the maintainers time to investigate
and prepare a fix before disclosing the issue publicly.

## Supported versions

Holark does not currently maintain long-term support release branches. Update
to the newest available release to receive security fixes.
